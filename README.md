# 首爾手冊 SEOUL · 2026.8.25—8.29

一份單檔 HTML 的個人旅遊手冊，獨旅五天四夜（民宿 3 晚 ＋ 仁川機場過夜 1 晚）。
打開 `index.html` 就是全部，沒有 build、沒有相依套件。

## 內容

總覽 → 住宿 → 費用 → 行程 → 當地 → 待辦。三組配色（丹青青綠／辣椒醬紅／漢江夜靛）
可切換，支援明暗底。待辦打勾狀態存在瀏覽器本機，斷網也能用。

## 標示慣例

- 行程時間軸的圓點：**實心 = 已訂妥**、**空心 = 想做但沒訂**、**半實心 ◐ = 待確認**
- ◐ 的項目旁邊一定有文字寫清楚在等什麼，不要當成已確認的資訊使用
- 台幣與韓元**分開列小計，不相加**——混加會得到一個看起來精確、實際無意義的數字

## 未放入的資訊

訂單編號、PIN 碼、護照資料一律不放在這個檔案裡（這是公開 repo）。
取票、入住需要的訂單編號請直接開 Trip.com App。

## 線上網址

https://karen-lian.github.io/sel2608/

啟用方式：Settings → Pages → Source 選 **Deploy from a branch** →
Branch 選 `main`、資料夾 `/ (root)` → Save。存檔後 1–2 分鐘生效。

## 修改

直接改 `index.html` 推 `main`，Pages 會自動重新部署。
推新版<b>不會</b>清掉已勾好的待辦——除非改動 `data-todo` 的 id 或 JS 裡的 `TRIP_ID`。
